Every measurement
has some error.
Know which kind.

A badly zeroed balance, a reading taken from the wrong angle, a shaky stopwatch thumb: errors are part of every experiment. Learn to tell systematic from random error, accuracy from precision, and how to put a number on how wrong you might be.

    Top exam tips for errors

    1. Name the type (systematic or random) and the source (instrument, person or design).
    2. Systematic errors push readings one way; repeating doesn't remove them. Fix them by calibrating or changing the method.
    3. Random errors scatter readings both ways; reduce them by repeating and averaging (or with a graph).
    4. Accuracy = close to the true value. Precision = close to each other. Don't swap them.
    5. % error = error ÷ true value × 100. With no true value, use the estimated error (half the smallest division) ÷ the measured value.
    6. Parallax: read scales with your eye perpendicular to the scale.
    7. Give % errors to sensible precision (one or two significant figures) and always say what they mean.
